# sulit-sites

Sample websites for small businesses in Metro Manila. All businesses shown are
fictional demo concepts, not real companies.

- `kusina/` - carinderia site, Taglish, daily menu + bilao packages
- `brightsmile/` - dental clinic, published price list + booking
- `glambox/` - salon, service menu + stylist profiles
- `kape-kanto/` - cafe menu and cover design
- `index.html` - portfolio page that links all of them

Static HTML, no build step, no dependencies.
